roobley's preemptive map is a successor to lama's practice map that aims to make finding your preemptive spikes easier using a datapack.

## Why use this new map?
This map is compatible with 50% Entity Distance (lama's required 175% minimum). \
You can add/remove chests and spawners just by flicking levers. \
You can control the T value easily. \
The map can be regenerated easily if broken.
